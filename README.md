 SkillSync – AI-Powered Career Assistant

**From preparation to placement.**

SkillSync is an AI-powered career assistant designed to help students prepare for interviews and improve their career readiness. It analyzes resumes, generates personalized interview questions, identifies skill gaps, and provides a preparation roadmap.

## Live Demo

**[Visit SkillSync](https://skillsync-frontend-16qq.onrender.com)**

Features

* **AI Resume Analysis:** Upload your resume in PDF format for analysis.
* **Interview Preparation:** Generate AI-powered interview questions based on your resume and job description.
* **Technical Questions:** Practice technical interview questions.
* **Behavioral Questions:** Prepare for HR and behavioral interviews.
* **Skill Gap Analysis:** Identify missing skills and areas for improvement.
* **Personalized Roadmap:** Get a structured preparation plan.
* **User Authentication:** Secure registration and login functionality.
* **PDF Support:** Upload resumes and access generated reports.

Installation & Setup

 1. Clone the Repository

bash
git clone https://github.com/Palak-Ranawat/Interview-Ai.git


2. Navigate to Project

bash
cd Interview-Ai


 3. Setup Backend

bash
cd Backend
npm install


Create a `.env` file inside the Backend folder:


Start the backend:

bash
npm run dev


### 4. Setup Frontend

Open another terminal:

bash
cd Frontend
npm install


Create a `.env` file inside the Frontend folder:

env
VITE_API_URL=http://localhost:3000

Start the frontend:

bash
npm run dev

Open the local URL provided by Vite.
